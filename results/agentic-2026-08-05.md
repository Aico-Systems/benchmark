## Failures worth knowing

- `groq` serves **no** sighted model. Both Llama 4 entries were retired and now
  404 on every id variant; absent from `/models`. Confirmed against our key.
- `deepinfra:Llama-4-Maverick` — `405 Tool calling is not supported for model`.
  Sighted and cheap, but unusable for an agentic node.
- `groq:llama-3.1-8b-instant`, `groq:gpt-oss-20b` — emit malformed tool
  arguments on the multilingual turn ("Failed to parse tool call arguments as
  JSON"). Small models buckle on a 4 kB schema.
- `openai:gpt-5.6-luna` — `Function tools with reasoning_effort are not
  supported`; our client always sends effort.
- `anthropic:claude-haiku-4-5` — rejects the image payload on the photo turn
  (400 invalid_request). Fine on text.
- `cerebras` shows a 58 s outlier on one multilingual run — median 717 ms, max
  58717 ms. Watch before trusting it in production.

## The bigger lever

`gpt-4.1-nano` does the decision in **613 ms** here but **3073 ms** inside the
live flow. The difference is not the model: the flow's system prompt is
**7100–8950 chars** against ~1200 in this scenario. Node instructions alone are
~3000 chars, and RAG `[TEAM KNOWLEDGE]` is appended per turn. Trimming the
prompt is now worth more than any further model swap.
